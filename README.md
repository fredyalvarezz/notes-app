#  Notes App

Aplicación web para gestionar notas personales, desarrollada con **React**. El proyecto permite a los usuarios registrarse, iniciar sesión y administrar sus propias notas mediante una interfaz sencilla, responsive y fácil de usar.

El objetivo principal del proyecto es poner en práctica conceptos fundamentales de React, manejo de estado, componentes reutilizables, Context API, Custom Hooks y persistencia de datos utilizando `localStorage`.

## Funcionalidades

*  Registro e inicio de sesión de usuarios
*  Edición del perfil
*  Cambio de contraseña
*  Creación de notas
*  Edición de notas existentes
*  Eliminación de notas con confirmación
*  Visualización completa de una nota mediante un modal
*  Búsqueda por título o contenido
*  Filtrado por categorías
*  Persistencia de datos mediante `localStorage`
*  Notificaciones tipo Toast
*  Diseño responsive
*  Estados de enfoque para navegación con teclado

## 🛠️ Tecnologías utilizadas

* **React**
* **JavaScript**
* **Vite**
* **CSS3**
* **Context API**
* **Custom Hooks**
* **localStorage**
* **HTML5**

## Almacenamiento de datos

La aplicación utiliza la API `localStorage` del navegador para almacenar:

* Usuarios registrados
* Sesión activa
* Notas de cada usuario

Las notas se almacenan asociadas a cada usuario, por lo que cada cuenta puede acceder únicamente a sus propias notas dentro del navegador.

Este proyecto fue desarrollado como parte de mi práctica como **Junior Full Stack Web Developer**, con especial interés en el desarrollo frontend utilizando React.
